# Built with ToGO

Open-source products running in production on the ToGO kernel, CLI and plugins. Each one is a
real, full-size codebase you can read to see how a ToGO app is put together: resources and
codegen, auth, tenancy, queues, realtime, and an MCP server for AI agents.

| Product | What it is | Repository | Website |
|---|---|---|---|
| **Mahaam** · مهام | Project management for agencies: projects, issues, time tracking, invoices, a customer portal, a feedback SDK and AI agents over MCP. | [fadymondy/mahaam](https://github.com/fadymondy/mahaam) | [mahaam.app](https://mahaam.app) |
| **Hosbah** · حوسبة | Server management and app hosting: bring your servers or Proxmox, zero-downtime deploys, databases, backups and tunnels, with an MCP server. | [fadymondy/hosbah](https://github.com/fadymondy/hosbah) | [hosbah.com](https://hosbah.com) |
| **Moharrik** · محرّك | The AI engine for a business: inbox, CRM, leads, email marketing, automation and research, every capability an MCP tool. | [fadymondy/moharrik](https://github.com/fadymondy/moharrik) | [moharrik.com](https://moharrik.com) |
| **Zekra** · ذكرى | Shared long-term memory for AI agents over MCP: hybrid recall, a knowledge graph, data sources and chat with citations. Its memory engine ships as ToGO plugins. | [fadymondy/zekra](https://github.com/fadymondy/zekra) | [zekra.dev](https://zekra.dev) |

Each repository's README has a "Built on ToGO" section listing the exact ToGO pieces it uses.
